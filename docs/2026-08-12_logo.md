# WarpTweet logo

## The Declared Route

The WarpTweet mark combines two system ideas without depicting cryptography itself:

- The clipped plate is a `.wt` manifest: a small, explicit declaration of the intended route.
- The single unbranched line enters and exits through equal endpoint bars: your computer and your remote server, with no WarpTweet-hosted relay between them.
- The squared construction reflects an exact, fail-closed profile rather than a compatibility fallback.

The mark deliberately avoids locks, shields, atoms, clouds, globes, birds, lightning, and network constellations. Those symbols would imply guarantees or infrastructure that WarpTweet does not claim.

## Source and outputs

[`src/lib/brand.ts`](../src/lib/brand.ts) is the single geometry authority. Astro uses it for the inline site mark and generates these static routes during the website build:

- `/brand/warptweet-mark.svg` for light surfaces.
- `/brand/warptweet-mark-reverse.svg` for dark surfaces.
- `/brand/warptweet-mark-mono.svg` for one-color reproduction.
- `/favicon.svg` for browser tabs.

The wordmark remains live text next to the symbol. There is no exported lockup with a system-font `<text>` element because that would render differently across platforms. A future fixed lockup must use reviewed outlines or a reproducibly bundled, appropriately licensed font.

The favicon is a separate 16-unit optical master. It retains only the declared route and equal endpoints, uses bevelled joins to avoid acute miter spikes, and supplies its own matte background so its contrast does not depend on browser chrome or inline SVG styles.

## Accessibility and use

- Inline marks next to the visible `WarpTweet` wordmark are decorative and hidden from assistive technology. The home link is named `WarpTweet, home`.
- Standalone marks need contextual alternative text such as `WarpTweet`, unless adjacent text already provides the name.
- The full mark is intended for 24 CSS pixels and larger. Use the favicon master below that size.
- Do not recolor individual parts, rotate the mark, animate the route indefinitely, add a middle node, or place the light asset on a dark surface.
- Forced-colors mode uses the user-agent link color. Print output uses a white footer and a black one-color mark.

## Verification and remaining publication work

`npm run verify` type-checks and builds the Astro site, then uses [`src/scripts/verify-site-output.mjs`](../src/scripts/verify-site-output.mjs) to check the generated SVGs for exact source geometry, required palettes, a contrast-preserving favicon tile, and forbidden active or externally referenced SVG content.

Before a packaged public release, add and visually verify a multi-frame 16/32-pixel ICO and an opaque 180-pixel Apple touch icon through a reproducible asset pipeline. The project also needs an explicit trademark and third-party brand-use policy. The current SVG mark and website integration do not by themselves settle those policy questions.
