# Repository instructions

- Put documentation in `docs/` with filenames prefixed `YYYY-MM-DD_` and a short, specific title.
- Prefer the ideal system design over expedient protocol or security compromises.
- Express roadmap sizing as productivity points, never calendar estimates.
- Keep types explicit and reject unsafe type workarounds.
- Avoid em dashes in user-facing copy unless they are necessary.
- Never add a classical fallback to a post-quantum-required profile.
- Never market a vendor-qualified OpenSSH authentication binding as standardized, quantum-proof, or FIPS validated.
- Never brand WarpTweet itself as experimental; scope that term only to OpenSSH's description of its vendor-qualified authentication binding.
- Treat `.wt` as a versioned WarpTweet manifest, never as a private-key container.
